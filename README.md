# CSS Layout Lab

> 从 CSS 常用单位到现代布局技术，通过独立知识示例与综合实战，掌握页面布局和多端适配。

**CSS Layout Lab（CSS 布局实验室）** 是一个基于原生 HTML + CSS 的学习项目。项目划分为 **6 大模块**：先了解常用 CSS 单位，再依次练习流体布局、Flex 弹性布局、rem / vw 布局、响应式布局和 Grid 网格布局。

每个知识点尽量提供可独立运行的示例；布局模块在知识示例之外，提供完整页面的综合实战。

## 📚 学习模块

| 序号 | 模块              | 知识重点                                                      | 实战方向           |
| ---- | ----------------- | ------------------------------------------------------------- | ------------------ |
| 01   | CSS 常用单位      | `px`、`%`、`em`、`rem`、`vw`、`vh`、`vmin`、`vmax`、`clamp()` | 独立知识示例       |
| 02   | 流体布局（Fluid） | 百分比宽度、`min-width`、`max-width`、流体容器                | 自适应文章页面     |
| 03   | Flex 弹性布局     | 主轴与交叉轴、排列、对齐、换行、伸缩                          | 导航栏与卡片列表   |
| 04   | rem / vw 布局     | 基于 `rem` 或视口宽度的尺寸换算、移动端适配                   | 移动端页面布局     |
| 05   | 响应式布局        | 媒体查询、断点、移动优先与桌面优先                            | 多端自适应网站     |
| 06   | Grid 网格布局     | 网格行列、区域、自动排列、自适应网格                          | 图片画廊或后台布局 |

> **模块区别：** `01-css-units` 学习单位本身的含义、计算规则和使用场景；`04-rem-vw` 则研究如何利用这些单位实现实际页面布局。两者有关联，但不是重复模块。

### 目录约定

- **`examples/`：知识示例。** 一个 HTML 文件重点演示一个概念或一个布局问题，便于修改参数、对比效果。
- **`practice/`：综合实战。** 将多个知识点组合成完整页面，可包含 `index.html`、`style.css` 和相关资源。
- **编号前缀：** `01-`、`02-` 等表示推荐的学习顺序；新增第一模块后，其余模块依次顺延。
- **`01-css-units/` 仅设置 `examples/`。** 单位基础通过独立小示例学习，综合应用放在后续布局实战中。

## 🚀 运行方式

项目优先采用**原生 HTML + CSS**，不依赖 Vue、React 或 CSS 工具类框架。

1. 使用 VS Code 打开项目目录。
2. 使用 Live Server 等本地静态服务器工具运行示例。
3. 打开 `src/` 中对应模块的 HTML 文件，查看并修改效果。
4. 使用浏览器开发者工具切换手机、平板和桌面视口，观察布局变化。

## 🧭 推荐学习顺序

1. **CSS 常用单位**：理解尺寸的计算规则及适用场景。
2. **流体布局**：让容器和子元素适应可用空间。
3. **Flex 弹性布局**：掌握一维排列、对齐和空间分配。
4. **rem / vw 布局**：练习移动端尺寸换算与等比例缩放。
5. **响应式布局**：使用媒体查询、断点与布局切换适配不同设备。
6. **Grid 网格布局**：掌握二维布局、网格区域和自适应列数。

## ✅ 练习规范

- 每个知识示例尽量聚焦一个核心问题，必要时添加简短注释。
- 对比不同屏幕宽度下的表现，尤其关注横向溢出、字体可读性和间距。
- 综合实战允许混用流体尺寸、Flex、Grid、rem、vw 和媒体查询。
- 优先使用原生 CSS 掌握布局原理，再考虑工具类 CSS 或框架。
- 完成一个独立示例或一项实战任务后，进行对应的 Git 提交。

## 🎯 学习目标

不仅记住 CSS 属性的写法，更要理解**尺寸如何计算、元素如何排列和伸缩、何时需要切换布局，以及如何让页面在不同设备上保持可用**。
